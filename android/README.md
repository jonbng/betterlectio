# BetterLectio Android

BetterLectio Android er den native Android-app i BetterLectio-familien: en moderne, gratis Lectio-app til danske gymnasieelever. Appen giver dig adgang til skema, lektier, opgaver, beskeder, fravær, karakterer og meget mere – hurtigt og uden reklamer.

Hovedwebsite: <https://betterlectio.dk>

## Baseret på Lectio++

**BetterLectio Android** (denne app) er baseret på **Lectio++** af **Oscar Spalk** (kildekode tilgængelig her: <https://github.com/oscarspalk/lectio_plus_plus>), som er udgivet under MIT-licensen. Stor tak til Oscar for at gøre projektet open-source. Se [`license.md`](license.md) for den fulde licens og ophavsret.

## Udvikling 🛠️

Klon dette repository og installer Flutter, så skulle du gerne kunne køre appen.
Eventuelt kan du installere [FVM](https://fvm.app/), så undgår du versionsfejl med forskellige Flutter-versioner (versionen er låst i `.fvmrc`).

```bash
flutter pub get
flutter run
```

Pull requests er velkomne.
